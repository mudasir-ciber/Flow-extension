HOW TO INSTALL IN GOOGLE CHROME (10 Seconds Setup):
------------------------------------------------------------
1. Google Chrome open karein.
2. Address bar mein ye type karein aur Enter dabayein:
   chrome://extensions
3. Top-Right corner par "Developer mode" ka toggle button ON karein.
4. Top-Left par "Load unpacked" button par click karein.
5. Is folder ("AMJADS-FLOW-EXTENSION") ko select kar lein.

Done! Extension Chrome mein install ho chuki hai.
